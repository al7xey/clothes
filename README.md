# Система учета размеров одежды

Консольное приложение для учета мерок пользователей и размеров их вещей:
хранит значения параметров (обхват груди, талии, бёдер, рост), подбирает
размер и проверяет, подходит ли вещь.

## Назначение
Помогает не ошибаться с размером при покупке одежды и вести учет размеров
всех членов семьи.

## Целевая аудитория
Покупатели одежды онлайн и семьи, которые ведут учет размеров домочадцев.

## Предметная область
Розничная торговля одеждой и личный учет одежды. Размер вещи определяется
набором параметров (мерок) и их значений.

## Основные сущности
- пользователь (`users`) — словарь `{id: данные}`;
- параметр (`parameters`) — словарь `{id: данные}`;
- значение мерки (`measurements`) — список словарей;
- вещь (`items`) — список словарей.

## Возможности
- просмотр пользователей и параметров, поиск параметра по названию;
- добавление мерки с проверкой допустимых пределов;
- запрет второй мерки одного параметра на одну дату;
- просмотр и удаление мерок пользователя;
- подбор буквенного размера (XS–XXL) по обхвату груди и отчёт;
- добавление вещей и проверка, подходит ли вещь по размеру;
- сохранение данных между запусками в JSON.

## Структура проекта
- `main.py` — точка запуска, меню, вывод данных;
- `parameters.py` — работа с параметрами;
- `users.py` — работа с пользователями;
- `measurements.py` — значения мерок;
- `items.py` — вещи и подбор размера;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод чисел и дат;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных
Файлы `data/*.json` содержат списки записей. Пример мерки:

```json
{"id": 1, "user_id": 1, "parameter_id": 1, "value": 98.5, "date": "2026-09-15"}
```
