# Система учета размеров одежды

## Назначение
Приложение хранит мерки пользователей (обхват груди, талии, бёдер, рост и др.) и размеры их вещей, помогает подобрать подходящий размер и проверить, подойдёт ли вещь.

## Целевая аудитория
Люди, которые покупают одежду онлайн и хотят не ошибаться с размером, а также семьи, которые ведут учёт размеров всех домочадцев.

## Предметная область
Розничная торговля одеждой и личный учёт одежды. Размер вещи определяется набором параметров (мерок) и их значений; у каждого пользователя свой набор мерок.

## Основные сущности
- Пользователь (User) — владелец мерок и вещей;
- Параметр (Parameter) — измеряемая характеристика (обхват груди, талии, бёдер, рост);
- Значение (Value) — результат измерения параметра у пользователя;
- Вещь (Item) — предмет одежды с указанным размером.

## Основные функции
- получение информации о параметре по коду (название, единица измерения);
- проверка корректности введённого значения мерки;
- подбор буквенного размера (XS–XXL) по обхвату груди;
- проверка, подходит ли вещь заданного размера пользователю;
- формирование текстового отчёта по мерке.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
